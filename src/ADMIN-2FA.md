# Admin Console — Two-Factor Authentication (TOTP)

The admin console (admin.foodyzz.com) uses **Firebase native TOTP multi-factor auth**.
The second factor is enforced at the authentication layer — an admin cannot obtain a
valid session token without it, so it can't be bypassed from the browser.

## One-time project setup (required before it works)

TOTP MFA needs **Identity Platform + TOTP** enabled on the Firebase project. Do this once:

1. Firebase Console → **Authentication** → **Sign-in method** tab.
2. If prompted, **upgrade to Identity Platform** (free tier covers a single admin; the
   project is already on Blaze for Cloud Functions, so no plan change).
3. Scroll to **Advanced** → **Multi-factor authentication** → enable **Authenticator app (TOTP)**.
4. Save.

> Until this is enabled, the console will show a message on the 2FA setup screen
> explaining it isn't turned on yet. Enabling it does **not** affect the mobile apps'
> customers (they use phone auth and are never asked for MFA).

## How it works for the admin

- **First login after this ships:** email + password → the console forces a **"Secure
  your account"** screen. Scan the QR (or enter the key manually) in Google
  Authenticator / Authy / 1Password / Microsoft Authenticator, enter the 6-digit code,
  and 2FA is enrolled.
- **Every login after:** email + password → **"Two-Factor Auth"** screen → enter the
  current 6-digit code → in.
- An existing valid session is **not** re-challenged (standard behavior); 2FA is checked
  at sign-in.

## Recovery — if the admin loses the authenticator

Because there's a single admin, keep a recovery path. Any of these removes the second
factor so the admin can log in with just email/password and re-enroll:

**Option A — Firebase Console (simplest):**
Authentication → Users → open the admin user → remove the enrolled MFA factor.

**Option B — Admin SDK (from `functions/` with service-account creds):**
```bash
node -e '
  const a=require("firebase-admin");a.initializeApp({projectId:"foodyzz-27b3e"});
  a.auth().getUserByEmail("ADMIN_EMAIL_HERE").then(u =>
    a.auth().updateUser(u.uid, { multiFactor: { enrolledFactors: [] } })
  ).then(()=>{console.log("MFA cleared");process.exit(0)});
'
```

After clearing, the next login goes straight to the enrollment screen again.

## Notes
- The TOTP secret is generated by Firebase and shown only in the browser during
  enrollment — it is never stored by us or sent anywhere.
- Code: `src/App.tsx` (login flow + gating), `src/components/auth/MfaChallenge.tsx`
  (sign-in), `src/components/auth/MfaEnroll.tsx` (enrollment).
