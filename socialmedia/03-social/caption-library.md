## Publishing checklist

Before any caption ships:
- [ ] Every number matches `../01-strategy/brand-source-of-truth.md`
- [ ] No claim on the forbidden list in `../00-research/nyc-ebike-rules.md` §10
- [ ] No pending legislation described as law
- [ ] Spanish written by a person, not a translation engine
- [ ] Image is real — no stock, no AI-generated bikes, no UniHamper assets
- [ ] Source cited in the first comment where a statistic is used
- [ ] Link goes to a page that exists
